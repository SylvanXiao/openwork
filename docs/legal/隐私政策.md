# 隐私政策（本地优先版）

> 适用范围：本隐私政策适用于「中国版 Working Agent」桌面客户端（以下简称"本软件"）。  
> 版本：草案 v1（2026-10-09），供内部评审，正式发布前需法务复核。  
> 关联文档：`用户许可协议.md`、`模型备案公示.md`。

---

## 一、我们是谁

本软件是一款**本地优先**的 AI 工作台，运行在您的个人电脑（Windows / macOS / Linux）上。我们（运营主体，待填写工商信息）作为软件的提供方，遵循《中华人民共和国个人信息保护法》（PIPL）、《网络安全法》、《数据安全法》及《生成式人工智能服务管理暂行办法》处理相关事宜。

## 二、核心原则：数据留在您的设备上

本软件的设计默认**不收集、不上传您的业务数据**：

- 您的工作区文件、对话记录、提示词、技能配置等**全部保存在您本机磁盘**，不经过我们的任何服务器。
- 本软件**不提供云端账号体系、不要求登录**（本地账号仅用于本机偏好存储，不出本机）。
- 我们**不训练、不分析**您的内容来改进模型或服务。

## 三、我们实际会处理哪些信息

依据"最小必要"原则，本软件仅在下述情形下处理信息，且多数需要您**主动开启或明示同意**：

| 信息类型 | 是否默认收集 | 用途 | 说明 |
| --- | --- | --- | --- |
| 设备/版本信息（OS、软件版本） | 仅在使用"发送反馈"时 | 定位问题 | 您主动触发才发送 |
| 崩溃日志 | 默认关闭，可开启 | 稳定性改进 | 不含业务内容，可在设置中随时关闭 |
| 匿名使用统计（如功能点击频次） | 默认关闭，可开启 | 产品优化 | 不含任何业务数据，可随时关闭 |
| 您配置的模型 provider 名称（非密钥） | 本地存储 | 记住您的偏好 | API 密钥仅存本机，不上传 |
| 您通过本软件调用的模型请求内容 | **不经我们** | — | 直接发往您所选的模型提供方，受其隐私政策约束（见第五节） |

**我们明确不收集**：您的文档正文、对话原文、提示词内容、API 密钥明文（密钥仅加密存于本机密钥库）。

## 四、告知与同意

- 任何可选的遥测/崩溃上报功能，在首次启用时均会**明确弹窗告知并取得您的单独同意**；您可随时在"设置 → 隐私"中关闭。
- 关闭后，相应数据立即停止收集。
- 本政策变更时，会通过软件内通知告知您重大变更，继续使用视为接受更新后的政策。

## 五、第三方模型服务（重要）

本软件是**客户端工具**：当您在设置中填入自己的模型提供方 API 密钥并选定模型后，您的提示词与上下文将**直接发送至您所选的模型提供方**（如 DeepSeek、通义、智谱、月之暗面等），由该提供方按其自身隐私政策与备案情况处理。

- 我们**不代您持有模型服务账号**，也不作为该生成式 AI 服务的提供方。
- 请您在使用前阅读并同意相应模型提供方的隐私政策与用户协议。
- 本软件所预置模型的备案/登记情况，见 `模型备案公示.md` 与软件"关于"页。

## 六、您的权利（依据 PIPL）

您对个人信息的处理享有以下权利，可通过本政策末尾的联系方式向我们行使：

- **查阅、复制、更正、补充**您的个人信息；
- **删除**您的个人信息；
- **撤回同意**（撤回不影响撤回前已进行的处理）；
- **携带**您的个人信息（可携权）；
- 对自动化决策结果（如适用）进行说明与拒绝。

由于本软件以本地存储为主，您的大部分数据**可直接在本机删除**（卸载软件或删除工作区目录即清除）。涉及我们侧少量信息的请求，我们将在 15 个工作日内响应。

## 七、未成年人保护

本软件不面向 14 周岁以下未成年人设计，亦不主动收集其个人信息。如您为未成年人，请在监护人陪同下使用。

## 八、安全措施

- 本机数据：API 密钥存放于操作系统提供的凭据库（如 Windows Credential Manager / macOS Keychain），不以明文落盘。
- 传输：与模型提供方的通信采用 TLS 加密。
- 我们侧：除您主动发送反馈所附信息外，我们不存储您的业务数据，故无集中泄露风险。

## 九、数据出境

本软件默认**不向境外传输您的业务数据**。当您选用境外部署的模型提供方时，相关数据将依据该提供方的政策处理，请您自行评估其数据出境合规情况。
