# 隐私政策（TGWork / TGWork 本地优先版）

> 适用范围：本隐私政策适用于「TGWork（TGWork）」桌面客户端及其可选云端平台服务「TGWork Cloud」（以下简称"本软件"或"本服务"）。

## 一、我们是谁

本软件是一款**本地优先**的 AI 工作台，运行在您的个人电脑（Windows / macOS / Linux）上；其可选的云端组件「TGWork Cloud」提供账号、用量计量、插件 / skills / 连接器市场等**平台服务**。我们作为软件的提供方，遵循《中华人民共和国个人信息保护法》（PIPL）、《网络安全法》、《数据安全法》及《生成式人工智能服务管理暂行办法》处理相关事宜。

## 二、核心原则：您的业务数据留在设备上

本软件默认**不收集、不上传您的业务数据**：

- 您的工作区文件、对话记录、提示词、技能配置等**全部保存在您本机磁盘**，不经过我们的任何服务器。
- 我们**不训练、不分析**您的内容来改进模型或服务。
- API 密钥仅加密存储于您本机凭据库，不上传。

## 三、云端（TGWork Cloud）实际处理哪些信息

为提供可选的云端平台服务，云端**仅处理与"平台运营"相关的信息，绝不触及您的业务内容**：

| 信息类型 | 是否默认收集 | 用途 | 说明 |
| --- | --- | --- | --- |
| 账号信息（邮箱 / 登录凭证哈希） | 是（仅当您主动注册 / 登录云端） | 身份认证、账号管理 | 不使用云端则完全不收集 |
| 模型用量 / 配额计量 | 是（仅当使用云端计量） | 订阅与配额管理 | 仅计数，不含请求内容 |
| 插件 / skills / 连接器市场的下载与授权记录 | 是（仅当您使用云端市场） | 市场与授权管理 | 不含您通过它们处理的业务数据 |
| 设备 / 版本信息 | 仅在使用"发送反馈"时 | 定位问题 | 您主动触发才发送 |
| 崩溃日志 | 默认关闭，可开启 | 稳定性改进 | 不含业务内容，可随时关闭 |
| 匿名使用统计 | 默认关闭，可开启 | 产品优化 | 可随时关闭 |

**我们明确不收集**：您的文档正文、对话原文、提示词内容、API 密钥明文。

## 四、告知与同意

- 任何可选的遥测 / 崩溃上报功能，在首次启用时均会**明确弹窗告知并取得您的单独同意**；您可随时在"设置 → 隐私"中关闭。
- 使用云端服务前，会在软件内明确告知并征得同意。
- 本政策变更时，会通过软件内通知告知您重大变更，继续使用视为接受更新后的政策。

## 五、第三方模型服务（重要 · 合规优势）

本软件是**客户端工具**：当您在设置中填入自己的模型提供方 API 密钥并选定模型后，您的提示词与上下文将**直接发送至您所选的模型提供方**（如 DeepSeek、通义、智谱、月之暗面等），由该提供方按其自身隐私政策处理。

- 我们**不代您持有模型服务账号**，也**不作为该生成式 AI 服务的提供方**，故不触发《生成式人工智能服务管理暂行办法》项下的算法备案 / 深度合成安全评估等 AI 服务专项义务。
- 请您在使用前阅读并同意相应模型提供方的隐私政策与用户协议。

## 六、您的权利（依据 PIPL）

您对个人信息的处理享有以下权利，可通过本政策末尾的联系方式向我们行使：

- **查阅、复制、更正、补充**您的个人信息；
- **删除**您的个人信息；
- **撤回同意**（撤回不影响撤回前已进行的处理）；
- **携带**您的个人信息（可携权）；
- 对自动化决策结果（如适用）进行说明与拒绝。

由于本软件以本地存储为主，您的大部分数据**可直接在本机删除**（卸载软件或删除工作区目录即清除）。云端账号相关信息的请求，我们将在 15 个工作日内响应；您亦可随时在账号设置中**注销云端账号**。

## 七、未成年人保护

本软件不面向 14 周岁以下未成年人设计，亦不主动收集其个人信息。如您为未成年人，请在监护人陪同下使用。

## 八、安全措施

- 本机数据：API 密钥存放于操作系统提供的凭据库（如 Windows Credential Manager / macOS Keychain），不以明文落盘。
- 传输：与模型提供方及云端的通信采用 TLS 加密。
- 我们侧：除您主动发送反馈所附信息外，我们不存储您的业务数据，故无集中泄露风险。

## 九、数据出境

本软件默认**不向境外传输您的业务数据**。当您选用境外部署的模型提供方时，相关数据将依据该提供方的政策处理，请您自行评估其数据出境合规情况。
